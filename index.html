📱 本机备份

把所有客源、盘源、标签数据导出为一个 JSON 文件，保存到手机本机。换机或重装时可导入恢复。

☁️ Supabase 自动云备份

配置后，每次新增/编辑客源、盘源、标签都会自动上传到你的 Supabase 云数据库（防抖 2 秒合并请求，不阻塞操作）。换设备时填同样配置即可拉取恢复。

首次使用：1) 注册 supabase.com 建项目；2) SQL Editor 执行建表 + 授权： create table sb_sync_bucket (user_key text primary key, payload jsonb not null, updated_at timestamptz default now()); grant insert, update, select on sb_sync_bucket to anon; 3) 在项目设置 → API 里复制 URL 和 anon key 填到上方。

🐙 GitHub 备份（第二重保险）
